**О проекте:**
Данный проект представляет собой адаптивную систему регулирования уличного освещения на базе микроконтроллеров ESP, предназначенную для оптимизации энергопотребления и повышения уровня безопасности дорожного движения.
Проблема
В России значительная часть дорог (особенно местного значения и в сельских поселениях) не имеет регулярного освещения. По данным Росавтодора, освещено лишь около 54,6% дорог. Отсутствие света является сопутствующим фактором в 15–20% ночных ДТП с участием пешеходов. При этом на малопосещаемых участках наблюдается нерациональное использование электроэнергии.

**Цель**
Разработать автоматическую систему освещения удаленных от города
трасс в зонах пониженного процента населения или редко посещаемых
дорог.

**Варианты моделей системы**
В ходе работы были рассмотрены и протестированы три концепции:
  Простая модель: Ультразвуковой/лазерный датчик замеряет расстояние и включает фонарь. Устройства работают независимо.
  Сложная модель (Mesh-сеть): Обнаружение объекта, измерение скорости (через WiFi-сигнал), формирование пакета данных и передача по mesh-сети (без роутера) следующим устройствам для упреждающего включения.
  Продвинутая модель (ИИ): Использование камеры (ESP32-CAM) и обученной нейросети для распознавания объектов и их скорости с последующей передачей данных по сети.
*(На текущий момент реализован и доведен до стабильной работы прототип на базе первой модели с применением многозадачности FreeRTOS).*

**Аппаратное обеспечение (Макет 1:100)**
Для сборки макета использовались следующие компоненты:
  Микроконтроллер: ESP32 (ESP32-S3 N16R8)
Датчики:
  Ультразвуковой дальномер HC-SR04
  Лазерный дальномер VL53L0X (более точный)
  Датчик интенсивности света GY-302 (BH1750)
  Индикация и звук: OLED-дисплей 128x64, динамик, светодиоды.
  Прочее: Резисторы на 220 Ом, соединительные провода, монтажная плата, макет из фанеры.
  Программная реализация

Код написан в среде Arduino IDE с использованием FreeRTOS для ESP32.
Алгоритм работы: при приближении объекта ближе 40 см фонарь включается. После проезда объекта фонарь продолжает гореть еще 5 секунд (режим удержания).
Борьба с помехами: реализован алгоритм медианного и экспоненциального сглаживания (фильтрации), чтобы датчик не реагировал на случайные скачки и не вызывал мерцание лампы. Также применен гистерезис для подтверждения состояния.
Многозадачность: используются прерывания (ISR) для считывания эха и отдельная задача FreeRTOS для опроса датчика, что исключает блокировку процессора.

**Перспективы развития:**
  Доработка устройства с использованием более точных компонентов.
  Интеграция ESP32-CAM и обучение нейросети для детекции объектов в сложных погодных условиях.
  Настройка mesh-сети (ESP-WIFI-MESH или ESP-NOW) для синхронной работы фонарей на трассе.
  Адаптация системы для подключения к реальным фонарям высокого напряжения через реле.
